# Hello 问候技能

一个最小化的示例技能，用于验证技能机制是否正常工作。

## 使用流程

被调用时，本技能将：

1. 以友好的语气向用户问候。
2. 简要复述用户的请求内容。
3. 建议下一步操作。

## 辅助脚本

技能自带问候脚本（相对于技能安装目录）：

```bash
python3 scripts/hello.py "用户的请求内容"
python3 scripts/hello.py --name 小明 "帮我看看代码"
```

脚本会根据当前时间生成问候语、复述用户请求并给出下一步建议，可直接将输出用于回复。

## 注意事项

- 问候语保持简短自然。
- 不要编造事实，只总结用户实际说过的话。
